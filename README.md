# 실시간 엔진 응용 리서치 (게임엔진/미림 프로젝트)

미림(재미나이 AI 캐릭터)을 나중에 실시간 캐릭터 시스템(언리얼/유니티/NVIDIA ACE류)으로
옮길 때 참고할 응용 착안점을, 이미 완성된 소프트웨어들을 선입견 없이 뜯어보며 쌓아가는
리서치 기록. 저장소 이름은 "blender-architecture-research"로 시작했지만, 대상 소프트웨어를
Blender 한정으로 좁히지 않고 계속 확장 중.

## 다음 단계

지금까지는 "조사만 쌓인 상태"— 실제 의의는 조사 자체가 아니라 이 중 하나를 실제로
미림 프로젝트(또는 자체 툴)에 프로토타입해보는 단계로 넘어가야 생긴다. 다음에 이
주제가 나오면 새 기술을 또 조사하기 전에 **"어느 착안점을 어디에 적용할지"부터 좁힐 것.**
현재 가장 우선순위 높은 후보는 01번 문서의 Rigify 패턴(언리얼/유니티에도 없는 성숙도),
그 다음으로 실제 구현 단계에 가면 02+03번의 "REST-over-소켓 프로세스 분리"가
아키텍처 뼈대로 바로 쓰일 만함.
